# SSH 批量部署

客户端运行一条命令即可安装并接入目标设备。省略 `--via` 时，客户端直接通过 SSH 部署；指定网关时，由网关执行 SSH，安装完成后通过 relay 使用目标。

```bash
rex deploy root@192.168.1.101
rex deploy --via gateway --port 9000 app101=ops@172.16.126.101 app102=root@172.16.126.102
```

仓库内可用 `./rex.sh deploy ...`，或通过 `npm install -g .` 安装 `rex`。客户端需要 Node.js 18+、curl 和 tar。目标保持现有安装器的 Linux x86_64、systemd 和 root/sudo 要求。网关部署需要网关运行包含 `deploy.ssh` 的当前版本，并已配置在客户端 `hosts.json` 中。

## 命令参数

| 参数 | 默认值与用途 |
| --- | --- |
| `--via <网关名>` | 可选。省略时直连，指定时使用已登记的单跳网关 |
| `--port <端口>` | daemon 监听端口，默认 8791，同次部署全部目标使用同一值 |
| `--ssh-port <端口>` | SSH 端口，默认 22 |
| `--identity <私钥路径>` | 可选。直连时读取客户端路径，经网关时读取网关服务用户可访问的路径 |
| `--package <运行包>` | 可选。使用本地 tar.gz 及相邻 `.sha256`，省略时客户端下载一次稳定发布包 |
| `--host-key <SHA256指纹>` | 可选。明确提供单台目标的可信 SSH 指纹，适合非交互部署 |

目标格式为 `[别名=]用户@IPv4`。省略别名时自动生成 `host-<IP用短横线连接>`。同名端点冲突在部署前报错，已有同端点配置可重复部署。

## 执行流程

1. 客户端下载并校验一次运行包，或读取 `--package` 的本地包。
2. 获取并确认目标 SSH 指纹。已记录的指纹发生变化时停止该目标。
3. 尝试指定私钥、默认私钥或 SSH agent。认证失败时，无回显询问该目标的 SSH 密码；普通用户需要提权时，单独询问 sudo 密码。
4. 通过 SFTP 将运行包、校验文件和安装脚本传入目标，调用安装器的 `--package` 模式。目标无需访问公网。
5. 取回目标的可信证书和 token，TLS 私钥保留在目标。执行实际直连或 relay 命令验收，确认运行身份。
6. 验收成功后保存客户端凭据，并原子更新 `hosts.json`。逐台显示结果，单台失败继续其他目标，存在失败时命令返回非零退出码。

经网关时，客户端通过网关现有认证 TLS 入口上传一次包，再调用专用 `deploy.ssh` 操作。网关仅接受自身允许网段内的 IPv4 目标，现有 relay 仍保持单跳及原有方法白名单。网关自身不能配置 `via`。

密码只用于当前任务内存和加密连接，不进入命令参数、环境变量、配置或安装日志。没有交互终端时，需要预先确认指纹或提供 `--host-key`，并具备免密 SSH 与 root/免密 sudo 条件。

## 安装与网络边界

`--port` 同时用于目标监听、接入验收和客户端配置。目标只需要向客户端或网关允许访问这个端口，不需要对公网映射。命令不修改防火墙或云安全组，验收失败时报告该目标失败，不把它登记为可用。

安装器直接运行 daemon，重复安装保持目标原有证书、token 和健康服务。它不会自动升级其他版本、迁移既有 supervisor 部署或更换端口。目标已有其他版本或不同端口时，使用相应升级或变更流程。

客户端配置保存在 `~/.config/remote-exec/hosts.json`，SSH 指纹保存在同目录 `ssh-hosts.json`，目标凭据保存在当前用户的私有 `credentials/` 目录，目录权限 0700、文件 0600。网关与目标的安装暂存文件在任务结束后清理，客户端不会覆盖其他主机条目。

## 验证

```bash
npm ci
bash scripts/build-release.sh
INSTALL_PACKAGE="$PWD/dist/remote-exec-linux-x64.tar.gz" npm run test:deploy
```

端到端测试需要 Docker，使用无公网出口、无端口映射的隔离 Debian 12 容器，验证真实 SSH、SFTP、sudo、systemd、指定 daemon 端口、直连和 relay 调用、免密与密码认证、配置登记、重复安装及失败保护。
